# Sword of Moonlight Kaitai Structs

Creates [Kaitai Structs](https://doc.kaitai.io/index.html) of the different binary files used by [Sword of Moonlight](https://doc.swordofmoonlight.com/).

Used the excellent file type documentation from the [Sword of Moonlight Compendium](https://doc.swordofmoonlight.com/editor/ff/map-evt-file-format/) with minor updates that I found were needed to parse the example **KING'S FIELD** project that comes with SoM and the example project I am using for [my other tool repo](https://github.com/jwhi/sword-of-moonlight-tools/tree/main/app/src/main/resources).

This repo was to allow others (and myself) to compile these structs to their language of choice using [one of the programming languages supported by Kaitai Structs](https://kaitai.io/#quick-start).

## Validation

Currently no automated validation.
You can double check my work and see parsed fields from your files using the [Kaitai Web IDE](https://ide.kaitai.io/). I have been running a copy locally to write and validate structs.
